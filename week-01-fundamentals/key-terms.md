# Key Terms

## Idempotency

- The system's ability to execute the same request only once no matter how many times it is sent.

- Real World: Customer double-taps M-Pesa send button. Only one transaction should process

- Test Angle: Verify that duplicate requests at both Cellipay ans Daraja API are rejected correctly

- Idempontecny Testing: Is ensuring that the same request is process once regardless of the number os times is sent
